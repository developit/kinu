# Separator

Semantic horizontal or vertical divider.

## Usage

```tsx
import {Separator} from 'kinu';

<Separator />
```

## Exports

| Name | Description | Rendered HTML |
| --- | --- | --- |
| Separator | Divider | `<div k="separator">` |

## Notes

- Rendered as a `<div>` so you can set orientation via attribute.
- Use decorative when the separator is purely visual.
